# Placement Drive Analyzer

A command-line tool in Python that tracks candidates through placement rounds (Aptitude, GD, Technical, HR), shows where candidates drop out, and produces a CSV for Excel / Power BI plus an HTML dashboard.

All sample data is **dummy data** generated by the `seed` command.

## Features
- Add companies and candidates, record round-wise results (Passed / Failed / Absent)
- Round-wise funnel per company (appeared, passed, pass %)
- Selection rate by section
- Export to CSV for Excel / Power BI
- Auto-generated HTML dashboard (`dashboard.html`)

## Tech Used
Python (argparse, sqlite3, csv), SQL (SQLite), HTML/CSS, Git/GitHub

## How to Run
```
python placement_analyzer.py seed
python placement_analyzer.py funnel
python placement_analyzer.py sections
python placement_analyzer.py export
python placement_analyzer.py dashboard
```
No extra libraries needed.

## SQL Concepts Practised
Primary and foreign keys, CHECK and UNIQUE constraints, JOIN (2 and 3 tables), GROUP BY, aggregate functions, conditional counting with `SUM(condition)`, `CASE` ordering, `ON DELETE CASCADE`
